指標定義：best / last / gap
Saving Ratio
每個測試點 i 的節材比例： ri = (V0,i − Vf,i) / V0,i。 V0 = initial_volume（初始設計材料體積）， Vf = final_volume（該測試回合結束時的設計材料體積）， 皆取自 testing_record.txt。訓練期間每 test_frequency 個 episode 做一次測試，共 N 個測試點（表中「測試點」欄）。
best
best = maxi ri，全部測試點中最高的 Saving Ratio。 點欄位標題可依此排序；比較區的「最終設計」與「score / 結束原因」都取自這個測試點 （若有並列，取最早出現者）。
last
last = rN，最後一個測試點的 Saving Ratio， 代表訓練結束時的表現。
gap
gap = best − last（Convergence Gap）。 衡量訓練穩定度：gap 越大，表示模型曾達到的好表現在訓練後期沒有維持住。 gap > 0.1 標為紅字，視為未收斂。

三者皆與 reward_type 無關，可跨 Run 直接比較；best、last 先四捨五入到小數 5 位，gap 由捨入後的值相減。 以 best 而非 last 作為排序依據的理由見 docs/adr/0001。
